# pstack 技能与工作流程审计

固定版本为 pstack 0.15.48，源码提交 `41e400932eca14f289e7db717a70455256b6d388`。本页覆盖 35 个非原则主技能和 22 个 `poteto-mode` 工作流程。每行记录从提示词拆出的职责、证据和 iBoard 接入条件。“部分覆盖”仅指可复用的现有行为，需继续完成所列差异；“待接入”表示此快照中无对应的完整入口。

宿主能力以 [pstack 的 Claude Code 适配说明](https://github.com/cursor/plugins/blob/41e400932eca14f289e7db717a70455256b6d388/pstack/docs/harness/claude-code.md) 为边界。Cursor Task 可对应 Claude Agent，部分状态和工作树能力需要单独实现。Cursor Automations、云代理与 Bugbot 的服务能力不会随提示词移植。带 GitHub 写入、用户联系或资源删除的阶段继续服从任务授权。实际项目验证仍走 iBoard 的断网执行与独立复验。
