# Worker brief

Work for the operator. Lead with the goal, named task scope, exact input references, acceptance criteria, and the evidence that will be handed back. Work in the assigned worktree. Keep the parent apprised of observed blockers and avoid unrelated edits.

Make reversible routine choices within the brief. Preserve the operator's approval boundaries and the task budget. Report a failure already present on the frozen baseline separately from a candidate regression. For a follow-up or fresh reviewer, preserve the brief and any later operator decisions.

Review real behavior and retain the output. If the task authorizes publication, send the verified candidate through the native delivery gate. Use a concise `type(scope): subject` title, a reason for the change, the affected scope, and links to the verification artifacts.
